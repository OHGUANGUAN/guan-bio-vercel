# Personal Biography Website

A simple personal biography website built with **HTML** and **CSS** and deployed using **Vercel**.

## About

This project serves as my personal website where I experiment with front-end development while creating a public online profile. It is a lightweight static site focused on clean design and responsive layout.

## Features

- Responsive design
- Built with pure HTML and CSS
- Fast static deployment
- Hosted on Vercel

## Tech Stack

- HTML5
- CSS3
- Vercel
- And of course, with some help from AI LLM xD

## Live Demo

🔗 https://gg-bio.vercel.app/

## Purpose

This repository is mainly used to:

- Practice front-end development
- Learn website deployment with Vercel
- Maintain a personal online biography
